NETCONF, RESTCONF & YANG

NETCONF vs. RESTCONF

NETCONF: Runs over SSH (TCP 830), uses XML encoding, and supports candidate/running datastores with network-wide commit/rollback. RESTCONF: Runs over HTTPS (TCP 443), uses JSON or XML (application/yang-data+json), and maps CRUD operations to HTTP verbs.

YANG Data Modeling (RFC 7950)

Yet Another Next Generation defines the structure and constraints of configuration and operational state data. Types include IETF (vendor-neutral standard), OpenConfig (operator-driven), and Native (Cisco IOS-XE specific).

YANG Node Types (Container, List, Leaf, Leaf-List)

Container: Groups related child nodes (maps to a JSON object {}, holds no value itself). List: Multiple keyed entries (JSON array of objects [{}]). Leaf: Single scalar key-value pair. Leaf-List: Array of scalar values [].

HTTP Methods & Status Codes

RESTCONF HTTP Verbs (CRUD)

GET: Read data (Safe & Idempotent). POST: Create a new resource or invoke an RPC (Not idempotent). PUT: Create or completely replace a resource (Idempotent). PATCH: Partially update existing fields. DELETE: Remove a resource.

Key HTTP Status Codes

200 OK (GET/PATCH success with body), 201 Created (POST/PUT created resource), 204 No Content (PUT/PATCH/DELETE success without body), 400 Bad Request (malformed JSON/YANG), 401 Unauthorized (bad credentials), 404 Not Found, 405 Method Not Allowed.

Tools, Catalyst Center & AI in Networking

Ansible vs. Terraform

Ansible: Agentless configuration management tool using YAML playbooks over SSH/NETCONF/RESTCONF (procedural/declarative). Terraform: Infrastructure-as-Code (IaC) provisioning tool using HCL and a state file to manage cloud and SD-WAN/ACI lifecycles.

Cisco Catalyst Center (formerly DNA Center) APIs

Intent-based Northbound REST APIs (/dna/intent/api/v1/...) use token authentication (X-Auth-Token) to automate device discovery, PnP provisioning, templates, and Client/Network Health assurance.

AI & Machine Learning in Network Operations (v1.2)

Supervised Learning: Trains on labeled telemetry to classify traffic or predict hardware failures. Unsupervised Learning: Detects anomalous baseline deviations (e.g., sudden latency spikes or DDoS bursts) without prior labels. Generative AI / AIOps: Assists with intent translation, root-cause summarization, and automated remediation workflows.
